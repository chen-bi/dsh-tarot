DeepSeek Harness Plugin

命运牌桌

在 DSH 里玩塔罗：你提问，助手给牌阵，你在聊天里报数字，牌桌翻开，助手逐张解牌。

GitHub 仓库 安装说明

两张牌桌，一份数据

侧边栏常驻「命运牌桌」，聊天时输入框上方出现小牌桌，牌面实时同步。

78 张韦特牌

大阿卡纳 + 四组小阿卡纳，正逆位、关键词齐全，原创 SVG 卡面。

6 种牌阵

单张、时间之流、关系之镜、事业十字、凯尔特十字、是否之间，也可自定义位置。

自动存档

抽满一局就落盘，含问题、牌阵、牌面与解读，最多保留 200 局。

安装

git clone https://github.com/chen-bi/dsh-tarot.git

然后在 DSH 里让助手装：plugin_manager → install_bundle，target 指向克隆下来的目录。装完刷新一次页面。

怎么用

  1. 跟助手说想问什么：「帮我看看这段感情」「明天面试怎么样」。
  2. 助手起局，告诉你牌阵和位置，让你在 1–78 里报 N 个数字。
  3. 牌桌上的牌当场翻开；助手逐张解，最后给结论和建议。
  4. 说「你帮我抽」让助手代抽，说「收起来」清掉这一局。
